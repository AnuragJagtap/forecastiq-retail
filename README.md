# ForecastIQ Retail

An end-to-end retail demand forecasting and inventory optimization platform built using Machine Learning and MLOps principles.

## Features

- Retail sales forecasting
- Inventory optimization
- Stockout prediction
- Overstock detection
- MLflow experiment tracking
- FastAPI inference APIs
- Streamlit dashboard
- Dockerized deployment
- CI/CD pipelines
- Monitoring and drift detection

## Tech Stack

- Python
- XGBoost / LightGBM
- MLflow
- FastAPI
- Streamlit
- Docker
- DVC
- Evidently AI
- GitHub Actions
